# wire-sizes report

This file is generated by `cargo run --locked --quiet --bin wire-sizes-report > REPORT.md`, run in `examples/wire-sizes/server`. Do not edit it by hand.

Each count is the HTTP message as the server's handler stack handled it: the request line, headers and body of a request, and the status line, headers and body of a response. The runner drives the router in process, so nothing here is a count of bytes on a socket. A real request also carries `host` and `content-length`, a real response carries `date`, and TCP and TLS framing is not counted, so every total is a lower bound. The `Bearer` token that the `json` and `cbor` runs send is a header of realistic length; the server does not verify it.
