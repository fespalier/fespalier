# Diagnostics: offline-first and CrateStack (`fespalier_cratestack`)

Since 0.10.0 (`packages/fespalier_cratestack/lib/`). These are not `fsp` diagnostics: `fsp` has none for this package,
because it adds no file kind, no `fespalier:` key and no command. They are the **run-time messages** of the package,
each read from the code and reproduced in a test before it was quoted, followed by the cause and the fix. `<op>`,
`<key>`, `<Type>` and `<error>` stand for the value in the message. The rules behind them are in
[`fespalier-offline`](../../fespalier-offline/SKILL.md) and [`fespalier-cratestack`](../../fespalier-cratestack/SKILL.md).
Lines that start with `fespalier_cratestack:` and are marked "debug" are printed with `debugPrint` in debug builds
only, never in release.

### Failures printed by their `toString`

A `CrateStackFailure` is an `Exception` that prints as one of these (they appear in a snackbar, a test failure or a
log). The wire message and `details` of a refusal are in the object but **never** in the text:

| Printed                              | Meaning                                                                                                             |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------------- |
| `CrateStackOffline`                  | No answer (no network, a timeout, a gateway or captive-portal page). The only one that falls back to the saved read |
| `CrateStackRefused(<status> <code>)` | A `4xx` the server decided (`CrateStackRefused(403 FORBIDDEN)`); an intent becomes `failed`                         |
| `CrateStackUnavailable(<status>)`    | A `5xx`, or an unreadable envelope (a bare `500` is this, not offline); the intent takes its next key               |
| `CrateStackInFlight`                 | `409` with `Retry-After`, or `TRANSACTION_ABORTED`: the same key is being answered; try later                       |
| `CrateStackUnauthenticated`          | `401`: the session is being renewed; the intent keeps its key                                                       |
| `CrateStackConflict(<code>)`         | `409` without `Retry-After`: the person resolves it; the intent is `conflict`                                       |
| `CrateStackCancelled`                | The provider that made the request was disposed or rebuilt: never an error to show                                  |
| `CrateStackNoLocalData(<key>)`       | K5                                                                                                                  |

## Symptoms with no message

| Symptom                                                        | Cause and fix                                                                                                                                                                                                                                                                                                                                                    |
| -------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| A queued intent never sends                                    | No trigger runs: nothing watches `autoSync` (once, in the root `layout.dart`), `reconnectSignal` is not overridden with `ConnectivitySignal.new`, no `syncTicker` override, or the intent belongs to another account (`crateStackScope`). A sync started by a signal within `minInterval` (10 s) of the last one is skipped; a manual sync always runs           |
| An intent stuck `failed`, with a code                          | The server refused it (`4xx`). Show `intent.reason`, then `intentQueue.discard(id)`. The server's message is never stored. `pendingIntents` does not list it (it is not undecided): list `intentQueue.list()` yourself                                                                                                                                           |
| An intent stuck `conflict`                                     | The server answered `409` without `Retry-After` (a stale version). Let the person resolve it, then `discard` and submit again                                                                                                                                                                                                                                    |
| A queued call ran **twice** after a token refresh              | The server namespaces idempotency keys by the `Authorization` header, so the refresh changed the namespace and the replay was a new request. The server must use the verified principal: `fespalier-cratestack`, [`server-contract.md`](../../fespalier-cratestack/references/server-contract.md). Do not queue a call whose double run matters on such a server |
| Another page's request is cancelled with this one              | A provider is **built inside** `ref.cancellable(() => ...)`: it runs in the same zone and its requests take this provider's token. `ref.watch` and `ref.read` other providers **before** `cancellable`, and make the body only the client call                                                                                                                   |
| "Offline copy" shows behind a captive portal or a gateway page | By design: an HTML page, or a bare `502`/`503`/`504`/`511`, is offline. Add `CrateStackPortalInterceptor` to the Dio so a `200` HTML page is rejected too                                                                                                                                                                                                        |
| The old account's intents or reads survive a sign-out          | `crateStackAccount.clear()` was not called, or it ran **after** `signOut()` (the scope is already null) without `scope:`. Call it before, or `clear(scope: leavingId)`                                                                                                                                                                                           |
| A page's `Served<List<Order>>` parameter does not bind         | The type is spelled differently from `data()` (a typedef, a prefix): `fsp` matches syntactically. Spell it exactly as the function returns it, with `FutureOr` unwrapped (`diagnostics-binding.md`)                                                                                                                                                              |
| Queued work vanished after a restart                           | `localStore` was not overridden: the default `InMemoryLocalStore` loses everything at exit. Use `HiveLocalStore`                                                                                                                                                                                                                                                 |
| A synced read shows the old value after a pull                 | The `data.dart` does not watch the tag (`ref.serve` watches `crateStackRevision(tag)`; a hand-written read of `ownedRows` must `ref.watch(crateStackRevision('notes'))`)                                                                                                                                                                                         |
| `A Timer is still pending` at the end of an offline test       | Your own ticker: override `syncTicker` with `ManualSyncTicker`. The package starts no timer                                                                                                                                                                                                                                                                      |
| A read throws a refusal instead of serving the saved copy      | By design: only `CrateStackOffline` falls back. A `403` is the answer; a `5xx` is `CrateStackUnavailable`                                                                                                                                                                                                                                                        |
| `adapters: [fespalier_cratestack]` does not compile            | The package has no `fespalier_adapter.dart`: wire it in `startup()`                                                                                                                                                                                                                                                                                              |
