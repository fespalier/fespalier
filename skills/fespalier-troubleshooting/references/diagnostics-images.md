# Diagnostics: `fespalier_image`

Since 0.9.0 (`packages/fespalier_image/lib/src/`). These are not `fsp` diagnostics: `fsp` has none for images, because the
package adds no file kind, no `fespalier:` key and no command. They are the **run-time messages** of the package, quoted from
the code (each is asserted by a test) and followed by the cause and the fix. [`fespalier-images`](../../fespalier-images/SKILL.md)
explains the rules behind them.

## Messages

| Id  | Message                                                                                                                                                                              | Cause and fix                                                                                                                                                                                                                                                                                                                                                            |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| M1  | `fespalier_image: "products/3.jpg" is not a URL and no image CDN is configured, so it is fetched as it is. Override imageCdnProvider in startup() (README, "Images").`               | `debugPrint`, in debug builds only, once per isolate. A `DirectUrlBuilder` (the default, `const ImageCdn()`) was given a source without a scheme, so it is fetched as it is and fails as a network error. Return `imageCdnProvider.overrideWithValue(const ImageCdn(builder: ...))` from `startup()`. In a test, `FakeImages().cdn(yourCdn)` in `pumpRouter(overrides:)` |

A builder or the buckets are misconfigured: a bug in the app, not a network failure. Read the line that follows, M3 to M10                                                          |

| M5  | `ImgixUrlBuilder: domain "https://demos.imgix.net" must be a host name, like "demo.imgix.net", without a scheme or a path`                                                           | `domain` is empty or has a `/` or a `:`. ## Symptoms

| Symptom                                                                                                   | Cause and fix                                                                                                                                                                                                                                                                                                                        |
| --------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| The image flickers, or jumps, or a different size shows for a moment, in a hero flight                    | The hero has no `flightShuttle`. Flutter's default shuttle rebuilds the destination's child in the overlay, so the image measures the rectangle of the moment and asks for a URL. Use `route.imageHero(...)` on both pages, or `Heroes(shuttle: ResponsiveImage.flightShuttle)` in `transition.dart`                                 |
| The image loads twice (two URLs for one photo in the network log)                                         | A box that grew with `growWithBox: true` (it asks for the wider bucket, once, by design), or a precache at another width than the page (another bucket). Share one constant for the page's photo size between the page and the precache; leave `growWithBox` off for a box that animates                                             |
| The image is blurry                                                                                       | The bucket is chosen once, at the first layout, and only grows: a box that was small then (a panel that animates open, an `AnimatedSize`) keeps that bucket. Give a `width`, or `growWithBox: true`. `maxPixelRatio` (3 by default) also caps the ratio, so a 3.5× phone shows 3× pixels                                             |
| A blank image on the web, fine on a phone                                                                 | CORS. CanvasKit and skwasm fetch the bytes with XHR: the image server must send `Access-Control-Allow-Origin` on the image **and on a redirect's target** (EmgR redirects to its `CDN_BASE_URL` host; imgproxy: `IMGPROXY_ALLOW_ORIGIN`). `webHtmlElementStrategy: fallback` is the escape when the server cannot                    |
| A `403` from EmgR (the error view, `NetworkImageLoadException: HTTP request failed, statusCode: 403`)     | An `unsigned` URL against a server without `ALLOW_UNSIGNED_REQUESTS=true`, or a signature over another path than the URL's (the signer gets the path after the signature, leading `/` included: `/rs:fill:300:300/q:80/<source>.jpg`), or a source outside its `ALLOWED_SOURCES`. EmgR checks the signature before it parses the URL |
| A `400` from EmgR                                                                                         | An option the server does not take: gravity is `gr:` on EmgR (`g:` is grayscale), `sm` and `obj` are rejected, a `PRESETS` name that does not exist, or `ALLOWED_PROCESSING_OPTIONS` that does not list a code. `ImgproxyUrlBuilder.emgr`, not the plain constructor, for EmgR                                                       |
| The test asks `flutter_test`'s fake `HttpClient` for images (400s, "creates an HttpClient"), or prints M1 | The test has no `FakeImages`. `imageCdnProvider.overrideWithValue(fakes.cdn(yourCdn))` in `pumpRouter(overrides:)` and in `test/routes/setup.dart`'s `overrides(pattern)`                                                                                                                                                            |
| `LayoutBuilder does not support returning intrinsic dimensions` (`IntrinsicHeight`, some dialogs)         | A `ResponsiveImage` without a `width` measures with a `LayoutBuilder`. Give it a `width` (it is then not measured)                                                                                                                                                                                                                   |
| A signer that computes an HMAC, or a key in a `--dart-define`                                             | The key ships with the app and is public: the resizer is an open proxy. Replace it with the backend's signed URLs (`SrcsetUrlBuilder`) or a lookup. `fespalier_image` has no parameter for a key on purpose                                                                                                                          |
