# Diagnostics: layouts, tabs and the root navigator

As of v0.4.0 (`cli/src/resolve.rs`, `emit.rs`). Each message is followed by its cause
and fix. `fespalier-layouts` and `fespalier-routing` explain the rules behind them.

| `` `tabs` must be a list of string literals naming the branches, e.g. `const tabs = ['home', 'search'];` ``                                                                                                              | `tabs` is read from the source: no variables, no spreads. | `container() must return a Widget: the container of the branch navigators`                                                                                                                                               |                                                                                                                                                                                                               |

A tab that **loses its state** has no message: a custom `container` that drops the
children from the tree (`fespalier-layouts`).

## `navigator.dart`

| Message                                                                                                                                                                                                                                                                                          | Cause and fix                                                                                     |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------- |
| `` expected `const navigator = RouteNavigator.root;` `` (or `RouteNavigator.shell`)                                                                                                                                                                                                              | The file has no `navigator` variable                                                              |
| `` `navigator` is declared twice ``                                                                                                                                                                                                                                                              |                                                                                                   |
| `` `navigator` must be `const`: write `const navigator = RouteNavigator.root;` ``                                                                                                                                                                                                                | `final` or `var`                                                                                  |
| `` `navigator` must be `RouteNavigator.root` or `RouteNavigator.shell`, written out: fsp reads it from the source ``                                                                                                                                                                             | Any other expression (a variable, a number). An import prefix (`fsp.RouteNavigator.root`) is fine |
| `` `RouteNavigator.shell` can't go back to a shell below a root-navigator route: go_router only lets its descendants use the root navigator or one above it. Put a layout.dart between the two, or drop this file ``                                                                             | `.shell` below a root folder with no layout between                                               |
| `this route is on the root navigator, but it sits directly in a tab layout, and go_router can't lift a direct child out of a shell (it is the first route of a tab, or one beside the others). Put it below a page.dart that stays in the layout, or move its folder out of the layout's folder` | A root route that is the first route of a tab, or a direct child of a (tab) layout                |

## `present.dart`

The only message is the warning `present.dart builds this folder's page, but there is no
page.dart here; it is ignored`. A `present.dart` also puts the route **and its
descendants** on the root navigator, so it can trigger the last `navigator.dart` error
above when the sheet is a first tab route or a direct child of a layout.

## Symptoms with no message

| Symptom                                                    | Cause                                                                            |
| ---------------------------------------------------------- | -------------------------------------------------------------------------------- |
| A full-screen route still shows the tab bar                | The route is inside the tab layout's folder and has no `navigator.dart` above it |
| `/profile/edit` built `/profile` underneath on a deep link | Expected: a `navigator.dart` route keeps its parent in the stack                 |
| The `navigatorKey` of a host router is ignored             | `AppRoutes.mount(navigatorKey: ...)` was not given the **host** `GoRouter`'s key |
