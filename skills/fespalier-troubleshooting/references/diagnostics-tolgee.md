# Diagnostics: translations (`fespalier_tolgee`)

Since 0.10.0 (`packages/fespalier_tolgee/lib/`). These are not `fsp` diagnostics: `fsp` has none for this package,
because it adds no file kind, no `fespalier:` key and no command. They are the **run-time messages** of the package and
of Flutter around it, each reproduced in a widget test before it was quoted, followed by the cause and the fix. `<key>`,
`<locale>`, `<tag>`, `<status>` and `<reason>` stand for the value in the message. The rules behind them are in
[`fespalier-i18n`](../../fespalier-i18n/SKILL.md).

## Messages

| Message                                                                                                                                                                                         | Cause and fix                                                                                                                                                                                                                                                                                                                                                  |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `No TranslationScope found above this widget.` with `` `context.tr`, `TrText` and `TranslationScope.of` read the translator of the nearest TranslationScope, and <Widget> has none above it. `` | **T1.** A `FlutterError`: `context.tr` or `TrText` ran above or outside the scope. `MaterialApp.router` got `routerConfig: router` instead of `TranslationScope.routerConfig(router, localeOf: ...)`, or a test used `pumpRouter`'s default app: pass `app: (router) => App(router: router)`, or wrap a subtree in `TranslationScope(locale: ..., child: ...)` |
| `Bad state: fespalier_tolgee: the base locale "<base>" is not bundled (bundled: <tags>)`                                                                                                        | **T2.** `Translations.baseLocale` is not one of the `bundled` locales: the base is the last link of every chain and must be bundled. Read through a provider it is wrapped in a `ProviderException` (`Tried to use a provider that is in error state.`). Add the locale to `BundledTranslations.load(locales: ...)` or fix `baseLocale`                        |
| `Malformed message for "<key>": <reason> (at character N)`, a `FormatException` reported **while formatting a translation** (library `fespalier_tolgee`), with the message and a caret          | **T3.** A message is not valid ICU. Debug only, **once per key**, through `FlutterError.reportError` (so a `testWidgets` fails on it); the text is shown as written, so a production build looks "untranslated" and says nothing. The reasons are below                                                                                                        |
| `Bad state: No translation for "<key>" in <locale> or its fallbacks`                                                                                                                            | **T4.** `FakeTranslations.strict()` or `fakeTranslations(strict: true)` was asked for a key no catalog in the chain has: a typo, or a key the test's `bundled` maps lack. Add it to the fake's `bundled`. Production never prints it; there `tr` returns the key                                                                                               |
| `FormatException: A catalog is a JSON object`                                                                                                                                                   | **T5.** A bundled file (or a remote one) is JSON but not an object (`[...]`, a string). From `BundledTranslations.load` it surfaces from `startup()`, so `splash.dart` shows the retry; a remote one is swallowed (see below). Export the file again as ARB or Tolgee JSON                                                                                     |
| `Unable to load asset: "assets/i18n/<tag>.arb".` and `The asset does not exist or has empty data.`                                                                                              | **T6.** Flutter's own error from `BundledTranslations.load`: a listed locale has no file, or `assets/i18n/` is not under `flutter: assets:` in `pubspec.yaml`, or the file is empty. `startup()` fails and `splash.dart` shows it. Pull the file, commit it, and list the folder                                                                               |
| `ClientException: Tolgee answered <status> to a save of "<key>"`                                                                                                                                | **T7.** The in-context panel's save (`PUT /v2/projects/translations`) was refused: a `401` or `403` is a key that is wrong or too narrow (it needs the `translations.edit` scope); `TOLGEE_API_URL` defaults to `https://app.tolgee.io`. Debug only                                                                                                            |
| `No MaterialLocalizations found.` (`AppBar widgets require MaterialLocalizations to be provided by a Localizations widget ancestor.`)                                                           | **T8.** A Flutter `FlutterError`. The route is in a language the app has no `MaterialLocalizations` for, and `localizationsDelegates: GlobalMaterialLocalizations.delegates` is missing from `MaterialApp.router` (and `flutter_localizations` from the pubspec): the scope overrides the locale to the route's                                                |
| `Target of URI doesn't exist: 'package:fespalier_tolgee/fespalier_adapter.dart'.` (`uri_does_not_exist`, in `lib/app.main.g.dart`)                                                              | **T9.** `fespalier: adapters: [fespalier_tolgee]`: the package ships **no** `fespalier_adapter.dart` (the setup is app code, which `startup()` already is). Remove it from `adapters:` and put `translationsConfig.overrideWithValue(...)` in `startup()`                                                                                                      |

### The ICU reasons (T3)

`Unexpected "}"`, `Expected a name`, `Unclosed "{"`, `Expected "," or "}"`, `A plural needs cases` / `A select needs cases`,
`Expected ","`, `selectordinal is not supported`, `Bad offset`, `Expected "{"`, and `A plural needs an "other" case` /
`A select needs an "other" case`. **A message that a gen-l10n or Tolgee file wrote with a lone apostrophe before a
brace** is not an error: it renders with the brace quoted (`l'{app}` shows `l{app}`); write `l''{app}`.

### Swallowed, so nothing is printed

`Tolgee CDN answered <status>` (a `ClientException` for any status but 200, 304 and 404) and the fetch errors of any
source are caught by the fetcher: the app keeps the cache, then the bundled text. `FakeTranslations is offline` is the
fake's version. Nothing prints and nothing throws; read `Translator.originOf(key)` (`TranslationOrigin.bundled` where
you expected `remote`) or `FakeTranslations.fetchCount(locale)` to find out.

## Symptoms with no message

| Symptom                                                      | Cause and fix                                                                                                                                                                                                                                                                                                      |
| ------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Raw keys on screen (`products.title`)                        | No `translationsConfig` override (`Translations.none`: every key is itself, silently; a test does not run `startup()`), or a typo in the key. Check `ref.read(translator('en')).originOf(key)`: `missing` is a typo or no catalog; `fallbackLocale` means the route's language lacks the key                       |
| The wrong language                                           | `MaterialApp.router` got the router, not `TranslationScope.routerConfig(...)`; `localeOf` does not match the URL (`localeSegment()` reads segment 0); spellings without a `$lang` folder (the locale is then the previous or the device's); or `$lang` is a `String` because no file asks for `required Lang lang` |
| `/xx/products` shows a page in English instead of not found  | `$lang` is a `String`: nothing asks for the enum. Add `required Lang lang` to a file of the folder                                                                                                                                                                                                                 |
| Texts never update after an edit in Tolgee                   | Tolgee publishes after **up to 15 minutes**; a locale is fetched once per container (restart, or `refreshOnResume: true`); `refreshOnReconnect` acts only after a **failed** fetch; on the web the CDN needs CORS headers (the browser console says so); a `404` or `304` changes nothing                          |
| The first paint shows bundled text, then the cached one      | Hive storage as `dataCacheStorage` answers a frame later; `PrefsDataStorage` answers on the first frame                                                                                                                                                                                                            |
| A text is right in the app and wrong in a test               | The test's `bundled` map differs from `assets/i18n/`, or `FakeTranslations` has not been pumped (a fetch lands on the next `pump`)                                                                                                                                                                                 |
| An `fsp test` smoke test throws T1                           | `test/routes/setup.dart` has no `app` that uses `TranslationScope.routerConfig`, or `overrides(pattern)` has no `fakeTranslations(...)`; a `$lang` route also needs a sample in `test.samples`                                                                                                                     |
| `l'{app}` renders `l{app}`                                   | ICU quotes: write `l''{app}`                                                                                                                                                                                                                                                                                       |
| `localeSpelling` / `relocate` do not compile (`AppManifest`) | Import the library that has `AppManifest`: `app.g.dart`, or the library `output_manifest` names                                                                                                                                                                                                                    |
| A language menu respells the path but keeps the old `$lang`  | `relocate(..., segment: 0)`: without `segment` a `$lang` segment is not replaced (spelled levels are respelled through `routes`)                                                                                                                                                                                   |
